## D-99 (env/deploy — RESOLVED this session) — stale globalThis-cached Prisma client
The web server predated both the D-92 fix and the `db:push`; `db.ts` caches the Prisma
client on `globalThis`, and Next HMR reloads route code but not the cached client. So the
live routes served a stale client and 500'd on `free_tier_usage` even though the table
existed. The P5-v2 executor PROVED the fix correct via a fresh-process repro
(`getFreeTierSnapshot(sam)` green). **RESOLVED:** team-lead restarted the web server;
re-verified `GET /api/billing/subscription` (user_qa_p5) → **200** with the Free-tier
snapshot. Lesson: schema/table changes on this env require a WEB-SERVER restart (not just
the worker), because of the globalThis client cache.

## D-100 (S2, OPEN — real product defect) — reasoning-model default breaks the AI first-taste
Even post-restart, the Free AI-assist first taste is broken for P5's seeded default model:
`qwen/qwen3.6-27b` (a REASONING model) returns ONLY `thinking`/`redacted_thinking` content
blocks (no `text`) at ghost-text token budgets (reproduced at 60 AND 400 tokens). The
routes' honest cut-off guard (D-04/D-38) then yields **502 "cut off, retryable"**, never a
usable suggestion. The metering gate CLEARS (ghost remaining 100, inline 50) and OpenRouter
resolves — so the moat's first taste is an empty-retry loop. Proof:
`p5-sam-rejudge-v2/repro-ai-assist.json`, `repro-ai-diagnostic.json`.
**Impact:** this is now the binding floor on P5's D11 (competitive edge / "taste the moat
before paywall") — the trust floor-drivers lifted, but a new-user reasoning-model default
can't produce a ghost-text/inline suggestion. **Fix directions (founder call on approach):**
(a) for ghost-text/inline-edit, request the model with thinking disabled or a
non-reasoning model; (b) raise the ghost budget + strip thinking blocks then use the text;
(c) pick a non-reasoning default model for the free on-ramp's quick-assist paths; (d) if the
model only returns thinking, surface a clearer "this model doesn't support quick suggestions
— pick another" message instead of a generic 502. Needs investigation of the ghost-text /
inline-edit request construction + how content blocks are parsed.

## D-101 (dev-only, latent S1-if-prod) — DEV_AUTH_BYPASS masks the no-auth control
`DEV_AUTH_BYPASS=true` silently authenticates header-less requests as the DEV user (no-auth
`GET /api/books` → 200 returning the dev user's books). Gated `NODE_ENV!=="production"`, so
not a live prod bug, but (1) it makes the no-auth 401 negative control unprovable in this QA
env, and (2) it is a latent S1 if the flag ever reaches a non-dev deploy. Proof:
`p5-sam-rejudge-v2/00-env-flags.json`, `31-noauth-books-list-401.json`.
**Recommendation:** add a startup assertion that hard-fails if `DEV_AUTH_BYPASS` is set while
`NODE_ENV==="production"` (belt-and-suspenders); low urgency. Tenant/ownership fences
themselves are proven elsewhere (P8 no-bypass sweep) — this is about the bypass flag, not the
gates.
