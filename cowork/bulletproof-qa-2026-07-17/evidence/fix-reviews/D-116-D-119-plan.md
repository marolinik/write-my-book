## Root cause recap

Quick-assist (ghost-text 60-tok, inline-edit) resolves its model via
`resolveCheapModelFor(userDefault)` = prefix + "/haiku". The seeded default
`openrouter-qwen36/*` prefix has its own `/haiku` slot aliasing the SAME
`qwen/qwen3.6-27b` reasoning model — so "cheap tier" never escapes the reasoning
model. `reasoning:{enabled:false}` is ineffective on it (D-100 evidence: 6/6
thinking-only). Result: ghost = 100% honest 422 (D-116); inline = 28–44s and
1655–3464 thinking tokens billed (~50–90× DeepSeek cost) (D-117).
