## Plottr (COMPLETE)
- Human-centered story-planning/outlining + story-bible tool. Timeline hub (chapters × plotlines × scene cards) → auto-generated Outline → manual export to Word/Scrivener.
- Timeline = hub; chapters headings renameable to Scene/Beat/Act; unlimited. [Timeline Overview](https://docs.plottr.com/article/54-timeline-overview) | [Chapters](https://docs.plottr.com/article/55-timeline-plotlines)
- Outline auto-generated from Timeline. [Plottr Overview](https://docs.plottr.com/article/8-plottr-overview) | [Outline](https://docs.plottr.com/article/68-outline-overview)
- Outline V2 (v2024.10.9) adds Plan view (Kanban to sequence beats/scenes) + Fulltext view. [Outline V2](https://plottr.com/outline-books/)
- Characters: cards w/ Custom Attributes from Character Templates (GMC, Snowflake, Enneagram, MBTI...). [Characters Templates](https://docs.plottr.com/article/85-characters-templates)
- Places (locations) — no world module; "You cannot create Templates for Places." [Places](https://docs.plottr.com/article/88-places-overview)
- Notes store lore/worldbuilding. [Notes](https://docs.plottr.com/article/73-notes-overview)
- Series bible via Project tab + Series View. [Series Bible](https://plottr.com/series-bible-hacks/)
- Templates: Custom Timeline Templates [doc](https://docs.plottr.com/article/149-custom-timeline-templates); Premium "Roadmap" Packs (full .pltr projects: Romance/Mystery/Thriller/Fantasy/Sci-Fi/Memoir/YA beat sheets) [doc](https://docs.plottr.com/article/147-using-premium-project-templates) | [Mystery pack](https://plottr.com/mystery-roadmap-pack/)
- AI: announced Mar 2024 brainstorming AI [Announce](https://plottr.com/plottrs-ai-future/); May 2024 workflow doc (off by default, paid add-on) [AI workflow](https://plottr.com/ai-in-plottr-workflow/); BUT 2026: "AI is NOT coming to Plottr" — removed from roadmap [2026](https://plottr.com/plottr-in-2026/). Not in official docs as shipped feature.
- HITL checkpoints: manual throughout; export only when user chooses. Export to Word/Scrivener.

## Sudowrite (COMPLETE)
- Pipeline: idea → Story Engine (brief → beats) → Story Bible (persistent character/world context) → Brainstorm (expansion) → Outline/Scenes (beat-by-beat structure w/ per-beat drafting hook) → Describe/Rewrite polish → Write/Draft. Story Bible injected as persistent context into every generation.
- Caveat: docs/sudowrite.com + sudowrite.com/blog bodies truncate to title in this env; facts grounded in third-party fully-rendered sources (Reedsy, Clarigital, Gizmodo) + confirmed page titles/URLs.
- Story Engine → beats → chapter prose: takes premise/genre/style/character list ("creative brief") generates scene/chapter beats then full prose. Gizmodo: founder James Yu - write "an entire novel in just a few days", processes scenes "beat-by-beat" [Gizmodo](https://gizmodo.com/gizmodo.com/sudowrite-launch-novel-writing-ai-software-story-engine-1850450016) | [Features docs](https://docs.sudowrite.com/getting-started/dQph1snuwbfMWG9wRjsNug/features/dq7YUMNy5ZMvKUJiRAisyT)
- Story Bible: stores characters, worldbuilding notes, plot summaries, writing-style guidance; "Sudowrite references the Story Bible in every generation" [Clarigital](https://www.clarigital.com/ai-atlas/specialist-tools/writing-content/sudowrite/) | [What is Story Bible docs](https://docs.sudowrite.com/using-sudowrite/1ow1qkGqof9rtcyGnrWUBS/what-is-story-bible/jmWepHcQdJetNrE991fjJC) | [Story Bible blog](https://sudowrite.com/blog/story-bible-template/)
- Brainstorm: outlining/idea agent - generates characters (names, backstory), worldbuilding, plot twists, dialogue, alternative scene directions. NOTE Reedsy: Brainstorm does NOT auto-integrate with Story Bible. [Brainstorm docs](https://docs.sudowrite.com/using-sudowrite/1ow1qkGqof9rtcyGnrWUBS/brainstorm/5xJUutV75BLU6u9LZndcDs) | [Reedsy](https://reedsy.com/blog/guide/book-writing-software/sudowrite/)
- Outline/Scenes (beat sheet): breaks a concept/beat into individual scene-beats and generates a draft from each beat. [Outline docs](https://docs.sudowrite.com/using-sudowrite/1ow1qkGqof9rtcyGnrWUBS/outline/3owKyHXUm1bCdp41b2Npjk) | [Scenes & Draft docs](https://docs.sudowrite.com/using-sudowrite/1ow1qkGqof9rtcyGnrWUBS/scenes--draft/49p5MTVxTKkVFEC5rVUzpY) | [Outline blog](https://sudowrite.com/blog/how-to-outline-a-novel/) | [Beats blog](https://sudowrite.com/blog/your-outline-sucks-heres-how-to-use-sudowrite-beats-to-fix-it/)
- Describe: inline prose-polish expands highlighted text with sensory "show don't tell" detail (five senses). [Reedsy](https://blog.reedsy.com/blog/guide/book-writing-software/sudowrite/) | [Describe blog](https://sudowrite.com/blog/show-dont-tell-writing-describe-feature/)
- Worldbuilding docs module: setting, factions, magic systems. [Worldbuilding docs](https://docs.sudowrite.com/using-sudowrite/1ow1qkGqof9rtcyGnrWUBS/worldbuilding/uc5NfWSz4x8Wm3S19LZeo8)
- Knowledge base/Context/Recap: Story Bible is persistent context store injected per generation. [Clarigital](https://www.clarigital.com/ai-atlas/specialist-tools/writing-content/sudowrite/) | [Glossary docs](https://docs.sudowrite.com/getting-started/dQph1snuwbfMWG9wRjsNug/glossary/1Symu5y4wtu65nQVYHjhxa)
- HITL: human populates Story Bible; human edits every beat/prose; Brainstorm alternatives chosen by user. Reedsy: Sudowrite "cannot be given free reign".

## NovelCrafter (primary verified - awaiting subagent for extra detail)
- Official blog "Plotting a Story with AI" renders fully - canonical pipeline: [Novelcrafter blog - Plotting a Story with AI](https://www.novelcrafter.com/blog/plotting-a-story-with-ai)
  - Codex = more than notes; codex entries added to AI's knowledge base so AI generates useful outputs; reference codex entries in prompts.
  - 1. Summary/Synopsis = first step; generate via Chat; cover inciting incident, major twist, climactic moment.
  - 2. Outline = structure; acts/chapters/scenes mapped onto outline. Generate via Chat conforming to archetype (3-act, hero's journey, "3 acts with 5 chapters each"), OR manually add acts->chapters->scenes. **"Create from Outline" button** makes all acts/chapters at once.
  - Templates = pre-made outlines: **3 Act Structure, Save the Cat, Hero's Journey**. Can make own templates as codex entries, AI uses them in chat.
  - 3. Chapters = generate/flesh out chapter summaries via Chat; detailed chapter summaries help weave subplots/synthesize story beats.
  - 4. Subplots = codex entry per subplot for referencing when generating scene beats later.
- Docs nav also shows: Plan section (Plan Interface, Plan Views incl storyboard/matrix, Planning with the Matrix spreadsheet, Create from Outline, Actions Menu), Codex section (types/aliases/tracking/series codex/categories/details/relations), Structure beats via story board. [Novelcrafter Plan category](https://www.novelcrafter.com/help/categories/plan#section-docs) | [Codex category](https://www.novelcrafter.com/help/categories/codex#section-docs)
